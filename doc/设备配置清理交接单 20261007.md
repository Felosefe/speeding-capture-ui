## 第 2 步：状态行改成「已同步 N 条 / 最后同步时间」

现有实现（改这一处即可，其余是瞬时状态文本，保留）：
- 394: `eventSyncStatus_->setText(eventSyncService_ ? (... isRunning() ...) : ...)` ← 常驻状态的计算点

做法：
1. `.h` 加成员：`QLabel* eventSyncCountLabel_ = nullptr;`（或直接复用 `eventSyncStatus_`）
   和 `qint64 lastSyncEpochMs_ = 0;`
2. `createEventSyncPage()` 里新增一行标签，例如
   `eventSyncCountLabel_ = new QLabel(QStringLiteral("已同步 0 条 · 从未同步"), ...)`，
   用 `QTimer`（5 秒）或复用已有的进度信号刷新。
3. 条数来源：对话框已有 `detectionPull_.repository`（`IEventRepository*`），
   用 `queryEvents(EventQuery{ deviceId = deviceId_ }, ...)` 的回调里取 `result.size()`
   —— 注意是**异步**，不要在构造函数里同步等。
4. 最后同步时间：`EventSyncService` 完成一轮时有信号（见 654 行附近
   `eventSyncStatus_->setText("同步操作完成：%1")` 的槽），在那里记 `lastSyncEpochMs_ = QDateTime::currentMSecsSinceEpoch()`
   并刷新标签。
