## 使用范围

本清单对应 A 侧已经完成的协议编解码、HTTP 客户端、UDP 发现、设备会话、FTP 配置及任务服务。它用于进入 A/B/C 联调前准备真实设备参数和记录验收结果，不替代固件接口说明。

## 安全检查

- Token 通过 `WindowsCredentialStore` 写入 Windows Credential Manager，引用格式为 `RV1126B/<device_id>`。
- `BoardApiClient` 仅把 Token 用于 `Authorization: Bearer` 请求头；完成组装后会清空临时内存。
- FTP 读取 DTO 只保存 `passwordConfigured` 状态，不保存或回显 FTP 密码；替换密码仅存在于单次更新请求中。
- 当前 A 侧网络、FTP 和凭据源文件不输出 Qt 日志。新增诊断时只允许记录操作名、设备 ID、耗时、HTTP 状态与稳定错误码，禁止记录请求头、响应体、Token、密码与完整 RTSP URL。
- 真机联调记录、抓包和截图在归档前应遮蔽 Token、FTP 密码和不应公开的网络地址。

## 自动化验证

在 Windows MSVC 构建目录执行 `ctest --output-on-failure`。A5 新增覆盖包括：HTTP 401/403/404/409/5xx 分类、证据长度校验、上下文销毁、UDP nonce、同设备端点更新、FTP 分页与重试委托、Credential Manager 生命周期，以及敏感日志边界检查。
