## 1. 跳过已完整 + 计数（跳过 N / 新写 N / 补全 N）

落点全在 `src/ui/Rv1126bDeviceManagementDialog.cpp`：

- `handleExportEventDetail()`（约 1666 行起）：算出 `folderName`、组好 `exportFiles_`（每个文件带
  `url` / `partPath` / `finalPath`）之后、**下载之前**插入判定：
  - 对 `exportFiles_` 里**需要下载**的项，若 `QFileInfo(file.finalPath).exists()` 且大小 > 0
    → 从本次下载列表里剔除；
  - 若**全部都已存在** → `exportSkipped_++`，`++exportEventIndex_`，直接 `exportNextEvent()` 返回，
    **一个字节都不下载**；
  - 若部分存在 → 只下缺的，本事件完成后 `exportRepaired_++`（补全）；
  - 全部新下 → `exportSucceeded_++`（新写）。
- `.h` 加三个计数器：`int exportSkipped_ = 0; int exportRepaired_ = 0;`（新写沿用 `exportSucceeded_`）。
- `startEventExport()`（约 1507 行）里把三个计数清零。
- `finishEventExport()`（约 1840 行附近，`exportSucceeded_/exportFailed_` 汇总处）把结果写成
  「跳过 N · 新写 N · 补全 N · 失败 N」。
- 注意：`downloadNextExportFile()`（1769）里 `QFile::remove(file.partPath)` + 下载 + rename 是
  **先删后写**，所以"已存在"判定必须在**组好列表后、进入下载前**做，才能真的省掉下载。

> 副作用（预期）：`检测结果` 里那约 610 个只有 `summary.txt` 的旧目录会被判为"不完整"，
